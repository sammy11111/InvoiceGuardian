# InvoiceGuardian

Service Invoice Exception Review — ingests a contract, a Statement of Work, and a service invoice, extracts typed facts with provenance, and produces evidence-cited exception findings routed through human approval. Built for the Kanz AI Training Hackathon (July 2026).

**Status: in progress.** Runtime and evaluation schemas complete and tested. Document generator, evaluation harness, and review UI in progress.

Every finding quotes its source verbatim. Nothing is ever sent, filed, or paid automatically — every action is a draft requiring human approval.
